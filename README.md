# 教务处项目管理平台

衢州职业技术学院教务处课程建设项目管理平台，覆盖「三个100课程」「百课工坊」等项目模块，以及教材、案例管理。

## 功能

- **项目/课程管理**：三个100课程、百课工坊等项目的新增、导入、编辑、删除（含删除前备份与恢复）。
- **节点填报与审核**：任务书签订、中期检查、结题验收三个节点，支持申请提交、审核通过/驳回、撤回申请。
- **角色权限**：管理员、审核人、填报人三级；填报人仅可见本人负责的课程，审核人和管理员可见全部。
- **附件管理**：云端存储、在线预览（PDF/图片/音视频/文本）、下载、按课程负责人归档。
- **进度可视化**：课程列表与详情展示任务书/中期/结题三条独立进度条。
- **变更记录**：填报人可新增变更申请，审核人审核。
- **成员与权限**：成员管理、手机号绑定认领账号。

## 技术栈

- React 18 + TypeScript + Vite
- WorkBuddy Cloud SDK（云端数据库 / 对象存储 / 认证）

## 本地开发

```bash
npm install
npm run dev
```

构建（含类型检查）：

```bash
npm run build
```

## 安全说明

- 账号、手机号、填报数据均保存在云端数据库，**不在本代码仓库中**。
- `src/cloud.ts` 中的 `publishableKey` 为平台公开密钥（设计上可公开，服务端通过 Origin 精确匹配校验），非私密凭据。
- 数据权限通过数据库行级安全策略（RLS）与服务端函数统一校验，不依赖前端隐藏。
- 请勿将任何 `.env`、令牌或真实数据提交到仓库（`.gitignore` 已排除相关文件）。
